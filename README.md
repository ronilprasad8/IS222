# IS222: Database Management Systems

This repository contains the coursework and technical implementations for **IS222: Database Management Systems** at the University of the South Pacific. The projects demonstrate a complete progression from conceptual database design to full implementation using MS Access and MySQL.

---

## 📂 Repository Structure

### 📁 [Assignment 1](./A1/) — SuvaTech Solutions (Individual)
**Focus:** Analyzing business operations and building a functional RDBMS in MS Access.
* **Author:** Ronil Prasad (S11231541)
* **Scenario:** A database system for SuvaTech Solutions, managing IT consultancy contracts, consultant security clearances, certifications, and cloud service subscriptions.
* **Key Components:**
    * **Database Design:** Crow's Foot notation ERD (MS Visio) and a comprehensive Data Dictionary.
    * **MS Access Implementation:** Relational tables with 100+ records, automated data entry forms (Client Registration, Project Assignment), and business reports.
    * **Queries:** SQL-based filtering for expired certifications, security clearance compliance, and subscription upgrades.

### 📁 [Assignment 2](./A2/) — USP Course & Placement System (Group)
**Focus:** Advanced Structured Query Language (SQL) for Data Definition (DDL) and Manipulation (DML).
* **Group Name:** Aura_Farmers
* **Members:** Ronil Prasad, Shivan Prasad, Praheel Kumar, Kunal Prasad
* **Scenario:** A relational system for the USP Continuing & Community Education (CCE) division to track candidate enrollments, qualifications, and industry job placements.
* **SQL Scripts:**
    * `Aura_Farmers_A2_CreateStructures.sql`: DDL script to generate the relational schema and integrity constraints.
    * `Aura_Farmers_A2_InsertData.sql`: DML script for populating the database with realistic industry data.
    * `Aura_Farmers_A2_Queries.sql`: Complex queries for management reports, including financial auditing and candidate shortlisting.
