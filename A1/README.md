## 🏢 Case Study: SuvaTech Solutions
The database manages complex operations for an IT consultancy, including:
* **Clients & Contracts:** Management of multiple service-level agreements (SLAs), project scopes, and renewal terms across different business divisions.
* **Consultants & Expertise:** Tracking consultant expertise levels (Junior to Principal) and security clearance levels (Confidential to Top Secret).
* **Certifications:** Monitoring training sessions and ensuring consultants maintain active certifications for specific projects.
* **Cloud & Software Licensing:** Managing client subscriptions across different pricing tiers, user limits, and billing cycles.

---

## 🛠️ Technical Components

### Database Design
* **Entity-Relationship Diagram (ERD):** Developed using **Crow's Foot notation** to visualize relationships between entities like Consultants, Projects, Clients, and Subscriptions.
* **Data Dictionary:** A comprehensive guide defining all attributes, data types, constraints (PK/FK), and table relationships.

### MS Access Implementation
* **Functional Queries:** Developed to retrieve critical insights, such as identifying expired certifications, listing contracts by client, and tracking cloud service upgrades.
* **Automated Forms:** Includes user-friendly registration forms for new clients and project assignment tools.
* **Business Reports:** Summary reports for tracking active contracts per sector and consultant certification renewal timelines.
